テーマと一緒に設定できるオプションです。

## カーソル効果

**Cursor effect** でポインター効果を追加できます。**Off**、**Sandevistan**、**Comet** から選択します。

{{< shot src="images/cursor-effect.png" alt="Cursor effect セクション" width="400" >}}

## サインインページ

**Choose a picture…** ボタンで、サインインボックスの背後に自分の画像を配置できます。プレビューの *Sign-in* タブで確認できます。画像はテーマと一緒に元のまま保存されます（SVG や 10 MB を超えるファイルは、幅最大 1920 px の WebP に変換されます）。**Use the web UI's picture** を押すと画像が取り除かれます。

![Sign-in page セクションと Sign-in シーンに表示された自分の画像](/images/sign-in-page.png)

## すべてのトークン

**All tokens** には Web UI のすべての色が一覧表示されており、特定の値を正確に指定したいときに使います。色の行と同様に、ポインターを合わせるとプレビューで塗られる部分に輪郭線が描かれます。

{{< shot src="images/all-tokens.png" alt="accent で絞り込んだ All tokens" width="400" >}}
