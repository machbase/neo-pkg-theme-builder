테마와 함께 정할 수 있는 선택 설정입니다.

## 커서 효과

**Cursor effect**로 포인터 효과를 추가할 수 있습니다. **Off**, **Sandevistan**, **Comet** 중에서 고릅니다.

{{< shot src="images/cursor-effect.png" alt="Cursor effect 섹션" width="400" >}}

## 로그인 페이지

**Choose a picture…** 버튼으로 로그인 상자 뒤에 직접 고른 그림을 넣을 수 있고, 미리보기의 *Sign-in* 탭에 표시됩니다. 그림은 테마와 함께 원본 그대로 보관됩니다(SVG나 10MB를 넘는 파일은 너비 최대 1920px의 WebP로 변환됩니다). **Use the web UI's picture**를 누르면 그림이 다시 제거됩니다.

![Sign-in page 섹션과 Sign-in 장면에 표시된 직접 고른 그림](/images/sign-in-page.png)

## 모든 토큰

**All tokens**에는 웹 UI의 모든 색이 나열되어 있어 특정 값을 정확히 지정할 때 씁니다. 색의 행과 마찬가지로 포인터를 올리면 미리보기에서 칠해진 부분에 윤곽선이 그려집니다.

{{< shot src="images/all-tokens.png" alt="accent로 필터링한 All tokens" width="400" >}}
