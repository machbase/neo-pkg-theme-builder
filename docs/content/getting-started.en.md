Open Theme Builder and choose the theme to start from.

## Open Theme Builder

After installing the package from the App Store, open **Settings** (the gear at the bottom of the left bar) → **Theme** → **Open Theme Builder**. You can also open the package from the PACKAGES list.

{{< shot src="images/settings-menu.png" alt="The Settings menu with Theme highlighted" width="230" >}}

{{< shot src="images/theme-dialog.png" alt="The Theme dialog with the Open Theme Builder button" width="480" >}}

## Choose a Starting Theme

Under **Start from**, choose a theme: the one you are using now, Dark, a preset, or one of your own themes. The presets themselves never change — what you save, once you change something, is your copy.

{{< shot src="images/start-from.png" alt="The Start from section with Dark and the four presets" width="400" >}}

## Name Your Theme

Type a name in the box next to **Theme Builder** at the top. The theme is listed under this name in **Settings → Theme**.
