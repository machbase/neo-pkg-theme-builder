Theme Builder를 열고 시작할 테마를 고릅니다.

## Theme Builder 열기

App Store에서 패키지를 설치한 뒤 **Settings**(왼쪽 바 아래쪽의 톱니바퀴) → **Theme** → **Open Theme Builder**를 엽니다. PACKAGES 목록에서 패키지를 열어도 됩니다.

{{< shot src="images/settings-menu.png" alt="Theme 항목이 강조된 Settings 메뉴" width="230" >}}

{{< shot src="images/theme-dialog.png" alt="Open Theme Builder 버튼이 있는 Theme 대화상자" width="480" >}}

## 시작할 테마 선택

**Start from**에서 시작할 테마를 고릅니다. 지금 쓰고 있는 테마, Dark, 프리셋, 직접 만든 테마 중에서 고를 수 있습니다. 프리셋 자체는 바뀌지 않으며, 무언가를 바꿔서 저장하면 내 사본이 됩니다.

{{< shot src="images/start-from.png" alt="Dark와 프리셋 네 개가 있는 Start from 섹션" width="400" >}}

## 테마 이름 정하기

맨 위 **Theme Builder** 옆의 입력란에 이름을 적습니다. **Settings → Theme**에 이 이름으로 표시됩니다.
