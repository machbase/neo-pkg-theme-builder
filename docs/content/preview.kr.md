미리보기는 색을 바꾸는 대로 웹 UI를 내 색으로 그려 보여 줍니다.

## 여섯 장면

각 탭에는 담고 있는 색의 개수가 표시됩니다.

- **Workspace**: 왼쪽 바, 탭, 사이드 패널, 에디터, 결과, 콘솔
- **Explorer**: 사이드 패널의 목록인 DB 탐색기와 패키지, 표 페이지
- **New tab**: Customize가 열린 상태(Widgets 패널이 드로어입니다)
- **Dialogs**: 배경 위의 대화상자, 입력란, 버튼, 메뉴, 툴팁
- **Status**: 배지, 상태 점, 메시지, 알림, 로그 레벨, 그리기에 실패한 탭, 토스트
- **Sign-in**: 로그인 페이지

## 색이 칠하는 곳 보기

색의 행에 포인터를 올리면 그 색이 쓰인 장면이 나타나 칠해진 부분에 윤곽선이 그려지고, 그 색이 보이는 모든 장면의 탭에 불이 들어옵니다. 미리보기의 아무 부분이나 클릭하면 해당 색으로 바로 이동합니다.

![Accent에 포인터를 올린 모습. 칠해진 부분에 윤곽선이 그려지고 장면 탭에 불이 들어옵니다](/images/preview-outline.png)
