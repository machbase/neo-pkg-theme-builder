Main changes in each version.

## 1.0.0 (2026-11-09)

- First release
- **Presets**: Light, Cyberpunk, Aemeath and Cement 98, usable as they are from **Settings → Theme**
- **Theme making**: shared colors, per-part customizing and all tokens, with a live preview of six scenes and contrast checks
- **Sign-in page picture** and **cursor effects**
- **Moving themes**: Export CSS and Import CSS
- Manual in English, Korean and Japanese
- Requires Machbase Neo 8.7.4 or later
