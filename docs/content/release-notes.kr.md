## 1.0.0 (2026-11-09)

- 첫 릴리스
- **프리셋**: Light, Cyberpunk, Aemeath, Cement 98을 **Settings → Theme**에서 그대로 사용
- **테마 만들기**: 공용 색, 부품별 Customize, 모든 토큰과 여섯 장면 실시간 미리보기, 대비 검사
- **로그인 페이지 그림**과 **커서 효과**
- **테마 옮기기**: Export CSS, Import CSS
- 영어·한국어·일본어 매뉴얼
- Machbase Neo 8.7.4 이상 필요
