Save the theme, switch to it, and take it to another browser.

## Use This Theme

**Use this theme** saves the theme and switches the web UI to it right away. **Undo** takes you back. With nothing changed it switches to the theme you started from as it is — Dark, the preset, or your theme — and saves no copy.

{{< shot src="images/use-this-theme.png" alt="The message after Use this theme, with Undo" width="451" >}}

## Save

**Save** keeps the theme without switching; **Save ▾ → Save as new theme** keeps a second version. Both wait until you change something: a preset as it is needs no copy.

{{< shot src="images/save-menu.png" alt="The Save menu with Save as new theme" width="317" >}}

## Switch Themes

Switch at any time in **Settings → Theme**: Dark and the presets are under *Ready to use*, your themes under *My themes*. Each card shows the colors of that theme. On one of yours, **Edit** (the pencil) opens it in Theme Builder and the trash can deletes it.

{{< shot src="images/theme-dialog-my-themes.png" alt="The Theme dialog with a saved theme in use under My themes" width="480" >}}

## Where Themes Are Kept

Your themes are kept **in this browser** — the browser's, whoever signs in on it — not on the server. The sign-in page shows the theme chosen in this browser, and its picture.

To take a theme to another browser or computer, use **CSS ▾ → Export CSS** and then **Import CSS** there. The CSS carries the colors; choose the sign-in picture there again.

{{< shot src="images/css-menu.png" alt="The CSS menu with Import CSS and Export CSS" width="404" >}}
