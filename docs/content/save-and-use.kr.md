테마를 저장하고, 바꿔 쓰고, 다른 브라우저로 옮깁니다.

## Use this theme

**Use this theme**는 테마를 저장하고 웹 UI를 바로 그 테마로 바꿉니다. **Undo**로 되돌릴 수 있습니다. 아무것도 바꾸지 않았다면 시작한 테마(Dark, 프리셋, 내 테마)로 그대로 전환하고 사본은 저장하지 않습니다.

{{< shot src="images/use-this-theme.png" alt="Use this theme를 누른 뒤 표시되는 메시지와 Undo" width="451" >}}

## Save

**Save**는 전환하지 않고 저장만 합니다. **Save ▾ → Save as new theme**은 다른 버전으로 하나 더 저장합니다. 둘 다 무언가를 바꿔야 활성화됩니다. 프리셋을 그대로 쓸 때는 사본이 필요 없기 때문입니다.

{{< shot src="images/save-menu.png" alt="Save as new theme가 있는 Save 메뉴" width="317" >}}

## 테마 전환

언제든 **Settings → Theme**에서 바꿀 수 있습니다. Dark와 프리셋은 *Ready to use*에, 내 테마는 *My themes*에 있습니다. 각 카드에는 해당 테마의 색이 표시됩니다. 내 테마에서 **Edit**(연필 아이콘)를 누르면 Theme Builder에서 열리고, 휴지통 아이콘을 누르면 삭제됩니다.

{{< shot src="images/theme-dialog-my-themes.png" alt="My themes에 저장한 테마가 사용 중인 Theme 대화상자" width="480" >}}

## 테마가 보관되는 곳

내 테마는 서버가 아니라 **이 브라우저**에 보관되며, 누가 로그인하든 같은 브라우저라면 같은 테마를 씁니다. 로그인 페이지에는 이 브라우저에서 고른 테마와 그 그림이 표시됩니다.

테마를 다른 브라우저나 컴퓨터로 옮기려면 **CSS ▾ → Export CSS**로 내보낸 뒤 그곳에서 **Import CSS**로 가져오세요. CSS에는 색만 담기므로 로그인 그림은 그곳에서 다시 골라야 합니다.

{{< shot src="images/css-menu.png" alt="Import CSS와 Export CSS가 있는 CSS 메뉴" width="404" >}}
